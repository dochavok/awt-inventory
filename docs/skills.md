# Skills

reviewed: 2026-11-27

Skills and spells aren't typed in: you pick them from the game's skill list. On this page, "skill" covers spells too.

## Adding a skill

Open **Skills** from the character's page. Under **Add a skill**, search the list by name; **Show every tree** adds the trees of the other classes. The search works as [search](search-and-export.md) does: it ignores capitals and accents, finds each word typed anywhere in a word of the name, and lists first the skills where every word typed starts a word ("sh" lists Shadow Step before Longshot). The list first offers the skills the character can take now: their prerequisites are on the character, they're in a tree the character's class and level allow, and the character hasn't taken them as often as allowed. Every other skill is listed below, under its own heading.

Some skills are printed in several trees, sometimes with different prerequisites in each. Such a skill is listed once, and it's offered first if any of its trees allows it.

With each skill you record **how it was gained** (Starting, Level-up, Quest, Trained under the old system, or Other), the **level** it was gained at, and any notes.

## Warnings, not blocks

The app warns you, but still lets you add the skill, when:

- a prerequisite isn't on the character (*missing prerequisite*);
- the skill is from another class's tree;
- the character's level is below the tree's entry level;
- the character already has the skill and can't take it again. Skills that can be taken several times are counted, and the warning appears only above their limit.

For a skill in several trees, you see the warnings of the tree that gives the fewest; if two give as many, the warnings of a tree of the character's own class.

DMs sometimes allow these, so the decision is yours. See [Troubleshooting](troubleshooting.md).

## What's shown

Each of a character's skills shows its name, tree (every tree, for a skill in several), usage (passive, 1/combat, 1/day…), tier and card text, from the skill list, with your own fields. The card text is the game's own, shown with the game owner's agreement.

A skill's grants come from the skill list, such as +2 CM or an extra arcane slot, and count for as long as the character has it: see [Equipping and totals](equipping-and-totals.md).

## Record check

The level chart says at which levels each class gains a skill or spell. Under **Record check**, the Skills page lists those levels, up to the character's, where no skill has that **level gained**. It's only a reminder: nothing is stopped. For the guide's made-up sample character:

## Removing a skill

**Remove** a skill added by mistake, like deleting any entry: **Undo** is offered for about 10 seconds. Skills can't be marked used or traded.

## Not in the list?

Skills that aren't in the list can't be added. Use **Not listed? Tell the maintainer** in the skill picker to report a missing or wrong skill: it opens the report form with that kind already chosen. See [Troubleshooting](troubleshooting.md).
